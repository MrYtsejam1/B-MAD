# Phase 4: Implementation

This phase is the iterative development phase using 2-week sprints with context-engineered stories.

## Sprint Structure

**Sprint Duration**: 2 weeks

### Sprint Ceremonies

1. **Sprint Planning** (Start of sprint)
   - Review sprint goal
   - Present context-engineered stories
   - Estimate stories
   - Commit to sprint backlog

2. **Daily Standup** (Async, daily)
   - What was completed yesterday
   - What's planned for today
   - Any blockers

3. **Sprint Review** (End of sprint)
   - Demo completed features
   - Review against acceptance criteria
   - Gather feedback

4. **Sprint Retrospective** (End of sprint)
   - What went well
   - What could be improved
   - Action items for next sprint

## Story Structure

Stories are stored in `stories/sprint-N/` directories.

Each story file follows the BMAD-METHOD™ context-engineered format:
- Story Overview
- Context (embedded PRD and Architecture sections)
- User Story
- Acceptance Criteria
- Implementation Details
- Technical Notes
- Testing Requirements
- Definition of Done
